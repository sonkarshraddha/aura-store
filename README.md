# AURA LUXE — E-Commerce Storefront

Precision engineered lifestyle, audio, and minimalist EDC gear storefront built with HTML5, Vanilla CSS3, and JavaScript.

## Features
- **Modern UI**: Dark / Light theme toggle with glassmorphism and smooth micro-animations.
- **Product Catalog**: Live search with debounce, category filtering, price slider, and sorting.
- **Interactive Cart**: Slide-out cart drawer, free shipping progress bar, promo code validation (`AURA20`, `FREESHIP`, `VIP50`).
- **Quick View Modal**: Interactive product preview with variant swatches and technical specifications.
- **Simulated Checkout**: Express Pay (Apple/Google Pay test fill), card authorization spinner, and canvas celebration confetti.
- **Wishlist**: LocalStorage-persisted favorite items drawer.

## Deploying to Vercel
Run the following in this directory:
```bash
npx vercel
```
When prompted:
1. Log in via your browser.
2. Select your Vercel scope/account.
3. Accept default settings (press `Enter`).
4. To deploy directly to production, run:
```bash
npx vercel --prod
```
